# Dataset

This project uses the **Olist Brazilian E-commerce Public Dataset**.

The dataset contains transactional e-commerce data collected from the Brazilian marketplace Olist and includes information about:

* Customers
* Orders
* Order Items
* Products
* Sellers
* Payments
* Customer Reviews

**Dataset Source**

https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

The dataset is publicly available on Kaggle and is not included in this repository due to its size and licensing considerations.
